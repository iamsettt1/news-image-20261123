A program that draws one image summing up 23 November 2026 world news:
the G20 summit in Johannesburg, the collapse of the COP31 climate talks,
a Russian ship burning off Finland, a drone strike in the Kyiv region,
a factory fire in Indonesia, a minister resigning in South Korea over an
AI exam scandal, and Nepal's PM meeting Modi in Delhi — plus the day's
smaller stories in a footer strip. Pure Python 3 standard library: the
program draws every pixel itself, including its own bitmap font, and
writes a deterministic 1024x1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png
```
